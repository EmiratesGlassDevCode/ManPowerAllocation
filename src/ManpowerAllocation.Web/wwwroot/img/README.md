# Application images

Place the Emirates Glass logo in this folder as **`emirates-glass-logo.png`**.

The application references `img/emirates-glass-logo.png` in the top bar, the
sign-in and access-denied panels, and the browser favicon, and resizes it to
fit (height only) so the original artwork is shown as-is. Replacing this file
with the official logo is all that is required — no code change.
